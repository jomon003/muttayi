# Contributing to Muttayi

Thank you for your interest in Muttayi! Here is how you can help.

## ✅ Welcome

- **Report plan data errors** — wrong price, validity, data, calls, SMS, subscriptions, or a missing/discontinued plan.
  The quickest way is the **Report** button on any plan card at [muttayi.com](https://muttayi.com) — it opens a pre-filled issue here.
  Or [open a plan error issue](https://github.com/jomon003/muttayi/issues/new?template=plan-error.yml) directly.
- **Request features** — [open a feature request](https://github.com/jomon003/muttayi/issues/new?template=feature-request.yml).
- **Ask questions / discuss ideas** — use [Discussions](https://github.com/jomon003/muttayi/discussions).

Reported issues are reviewed and fixed in the next plan data refresh. Fixed issues are labelled `fixed-in-refresh` and closed.

## ❌ Not accepted

- **Pull requests / code contributions are not accepted.** Any pull request will be closed without merging.
  If you have an idea or found a bug in the code, please open an issue instead.

## Tips for a good plan error report

1. Pick the operator and (for BSNL / Vi) your circle.
2. Say what Muttayi shows and what the operator's official site/app shows.
3. Add a link or screenshot from the operator's site if you can.
